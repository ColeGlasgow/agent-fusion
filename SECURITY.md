# Security policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in agent-fusion, please report it privately. Do **not** open a public GitHub issue.

Use GitHub's [private vulnerability reporting](https://github.com/ColeGlasgow/agent-fusion/security/advisories/new) for this repository, or email the maintainer directly. Include:

- A description of the issue and the impact.
- Steps to reproduce, or a proof-of-concept.
- Affected versions or commits if known.
- Any suggested mitigation.

You will receive an acknowledgement within a reasonable timeframe. Coordinated disclosure is appreciated; please give the maintainer time to investigate and ship a fix before public disclosure.

## Supported versions

agent-fusion is in the design phase and does not yet have released versions. Once releases begin, this section will document which versions receive security fixes.
